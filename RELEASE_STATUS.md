# Repository and archive status — 2026-10-25

## Current working snapshot

The `main` branch contains the code and measurements prepared for PeerJ Computer
Science manuscript 148632 (AI Application). `MANIFEST.json` lists this current
compact snapshot, with SHA256 hashes. The source implementation version remains
0.1.0; this is a reproducibility/evidence/documentation update.

The snapshot contains six-method general/poster comparisons, AesFA poster/OCR
evidence, a unified primary family of 25 statistical tests, spatial-control
manifests/masks and finite-ArtFID/CSD evidence. The archived measurements are
identified by their hashes. No training or original-image experiment was rerun
for this repository update.
